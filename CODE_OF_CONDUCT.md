# Code of conduct / Code de conduite

> **EN —** Be kind, critique the work and not the person, respect other people's privacy. Unacceptable: harassment,
> discrimination, sexual or violent content, publishing someone's personal data. Report a problem through the
> private contact in [`SECURITY.md`](SECURITY.md); the maintainer may warn, remove content, or ban. Adapted from
> the Contributor Covenant. The French text below is the reference version.

Nous voulons une communauté accueillante pour tous, quel que soit le niveau, l'âge, l'origine, le genre, l'orientation, le handicap ou la religion.

**Attendu :** bienveillance, critiques constructives portant sur le travail et non sur les personnes, respect de la vie privée d'autrui.

**Inacceptable :** harcèlement, insultes, propos discriminatoires, publication d'informations personnelles d'autrui (doxxing), contenu sexuel, spam.

**Application :** les mainteneurs peuvent modifier ou supprimer des contributions et exclure temporairement ou définitivement un participant. Signalements : via un avis de sécurité privé GitHub ou le contact indiqué dans le profil du dépôt.

Inspiré du Contributor Covenant 2.1.
