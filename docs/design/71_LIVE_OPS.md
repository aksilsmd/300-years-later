# 71 — Live ops (après le lancement Early Access)
Propriétaire : Product Owner · v1.0

## 1. Cadence
| Rythme | Contenu |
|---|---|
| Correctifs | sous 72 h pour tout S1 (crash, désync, perte de progression) |
| Mise à jour mineure | toutes les 2-3 semaines : recettes, chapeaux, équilibrage, qualité de vie |
| Mise à jour majeure | tous les 2-3 mois : un « Saison » (biome, époque, mode) |
| Défi du jour | automatique (graine UTC) ; Capsule mystère hebdomadaire |

## 2. Feuille de route EA (publique, sans dates fermes)
1. **Saison 0 — Période d'essai** (lancement) : 5 chapitres, 30 recettes, 12 contrats, 4 modes.
2. **Saison 1 — L'Époque Perdue** : ancrage illégal E-1 « Le Silence », biome Côte, 15 recettes.
3. **Saison 2 — Capsules** : Steam Workshop pour graines/capsules, concours de musées.
4. **Saison 3 — Recettes de la Communauté** : votes de recettes, éditeur de contrats.
5. **Version 1.0** : chapitre final, succès complets, localisation étendue, éventuelle console (IARC).

## 3. Événements saisonniers (cosmétiques, jamais payants)
Halloween (« Nuit des Chronomites »), fin d'année (« Le Synchro gèle »), anniversaire du jeu. Durée 2 semaines, récompenses en Chronos.

## 4. Suivi
- Tableau de bord hebdomadaire : avis Steam, crashs (si opt-in), parties/jour (Steam stats), Défi du jour.
- Tri des retours : Steam forums + Discord → GitHub Issues (label `community`).
- Note de patch systématique (FR/EN), rédigée « ton Odile » mais précise.

## 5. Règles éthiques
Aucun FOMO agressif, aucun achat aléatoire, aucun pass payant. DLC uniquement cosmétiques ou extensions de contenu clairement décrites, prix fixe.

## 6. Fin de vie / pérennité
Le jeu ne dépend d'aucun serveur propriétaire : il reste jouable tant que Steam fonctionne. En cas d'arrêt du développement : dernier patch, communication claire, mode LAN/ENet conservé.
